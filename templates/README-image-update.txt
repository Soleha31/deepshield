DeepShield template image update
================================

1. Stop Flask with Ctrl+C.
2. Make a backup of your current `templates` folder.
3. Extract the `templates` folder from this ZIP into your project folder:
   C:\Users\pc\OneDrive\Desktop\24AI02\Deepshield
4. Allow overwrite for the matching HTML files.
5. Start the app again with `python app.py`.
6. Open http://127.0.0.1:8000 and press Ctrl+F5.

Only HTML templates are included. Your existing static/style.css and app.py are not replaced.
The topic images use remote Unsplash image URLs, so internet access is needed to display them.
